# Referências

Esta lista reúne fontes usadas para orientar o protótipo.

## Segmentação e Dados Alimentares

- Okamoto, K.; Yanai, K. "UEC-FoodPIX Complete: A Large-scale Food Image
  Segmentation Dataset." ICPR Workshop on Multimedia Assisted Dietary
  Management, 2021.

## Detecção com YOLO

- Ultralytics. "YOLO11." Documentação e materiais técnicos do ecossistema
  Ultralytics. Usado como base para exportação e inferência do detector.
- Cheung, B. "From YOLOv2 to YOLO11: Food Detection Evolution." Referência
  prática sobre evolução de detectores YOLO em cenários de alimentos e
  conversão de datasets.

## Segmentação com SAM 2

- Meta AI. "Segment Anything Model 2." Referência conceitual para segmentação
  guiada por prompts.
- Repositórios de pesos ONNX do SAM 2.1 usados apenas como fonte operacional
  para experimentos locais em CPU.
